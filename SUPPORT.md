# Support

## Questions and discussions

Open a GitHub Discussion (if enabled) or an issue with the `question` label.

## Bug reports

Use the bug report issue template. Include reproduction steps and environment
details.

## Feature requests

Use the feature request issue template. Describe the problem and proposed
solution.

## Security vulnerabilities

Do not open a public issue. See [SECURITY.md](SECURITY.md) for the private
reporting channel.
